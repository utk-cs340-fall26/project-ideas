# Project Idea
This project idea is called Balance. This platform will be used to help college students balance every aspect of their lives. In this app, a user will be able to focus on their health and wellbeing both alone and alongside others. This centralized platform allows students to manage stress as well as improve their mental health by connecting with other college students to go on walks, organize workout classes or going to the gym together. Balance works to change students lives for the better in every aspect of health, academia, and social wellbeing.
# The Problem it Solves
This project solves many problems all in one. College students struggle so much managing classes, stress, assignments, mental and phsyical health, and exam anxieties every year of school. This platform would ensure daily check-ins, a social way to get active, and a new way to keep track of assignments well in advance.  
# Major Features
- Assigntment tracking
- Due date notifications
- Breathing exercises
- Daily journal entries
- Wellness check ins
- A post center for exercise groups/plans
- A chat area for users to interact
# Technologies to be Used
- React + Javascript for frontend
- Python FastAPI for backend software
- PostgreSQL for Database & Storage
- Google Calendar API for connecting Calendar features
# Intended Users 
The intended users for this application are college students — anyone juggling a full course load alongside the everyday stress of being a young adult away from home for the first time. This includes freshman trying to make new friends, upperclassmen managing heavier workloads, and any student who wants an easier way to stay accountable for both their grades and their health. This app can also help anyone post-grad who is working to stay on top of their wellbeing as they enter the real world.
