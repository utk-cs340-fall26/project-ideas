# Project Overview - Video Game Letterboxd
This project is a Letterboxd-esque website for videogames. Users can log games they have played (or are currently playing), rate, and review them.

## What Problem Does This Solve?
When it comes to other forms of entertainment, such as movies, there are already staple apps such as Letterboxd and Imdb that let their users express themselves through showing what they've recently watched or showcasing their favorite movies/shows. In creating this app, We hope to give people who enjoy video games the same space to keep track of what they've played in an aesthetic, easy to use way.

## Feature List:

### **Needs**

 - Search
    - Lets the user have the ability to look up games in our database, potentially other users too.
 - Log
    - Gives the users the ability to display the status of games that they have played, options include dropped, currently playing, played
 - Rate
    - Allows the users to place any game on a scale of 0-5 to share their opinions on it
 - Review
    - Lets the user write and share why they gave a game the score that they did

### **Wants**
 - Social Features
    - Lets the user share their reviews, whether through exporting a review or having users be able to follow each other
 - Want to play section
    - Allows the user to display games they eventually want to play

### **Niceties**
- Clean UI
    - Aside from creating a nice looking default theme, giving users the ability to customize the look of the app, or adding themes based on popular games could be a nice touch
- Custom Lists
    - Gives users the ability to group games into lists of their choosings and rank games within the respective list
- Sorting Options
    - Gives the ability the user to sort the games they've played, options include recently played, recently reviewed, time played, etc...
- Recommended Games
    - AI that suggests games a user might like based on how they rate games


## Technologies
- **Frontend:** React/Typescript
- **Backend:** Node.js/Express
- **Database:** Supabase
- **Third-Party API:** RAWG or IGDB for game data
- **Version Control:** Github

## Who Are The Intended Users?
The intended users of my application are anybody with an interest in video games. This app would allow them to keep track of what they've played and showcase their interests while also giving them a positive environment to comfortably share their opinions on games.
