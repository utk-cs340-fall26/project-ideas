# Project Idea
## Summary:
The project is a centralized healthcare management application that allows patients to manage their medical information in one place. Users can view upcoming and past appointments, track medications and reminders, and access lab results uploaded by their doctors.

## Problems it Solves:
This app would solve many problems. One would be it helps patients track there appiontments and keeps a log and timeline of what the appiontment was for and important notes. It also would help remind patients when and how to take medication if it was perscribed by there doctor. Another problem it could solve is it would have a easy and fast way to view lab results and would tell patients more about the healthy range and what there result means.

## Major Features:
+ Patient Dashboard
+ Appointment Management
+ Medication Management
+ Health Timeline
+ Lab Results
### Posibly:
+ AI Health assistant

## Tech Stack:
+ Backend: Python + FastAPI because of its ease of use and many libraries
+ Frontend: JavaScript + React + Vite
+ Database: PostreSQL + Supabase

## Intended Users:
Hospitals and Clinics as well as patients.
