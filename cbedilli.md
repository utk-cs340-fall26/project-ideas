# Project Proposal

## Idea 

Web-based app that allows businesses and creators to maintain a live, shared, procedure management system. Teams can create document templates, create live updates in real time, and allows for easy team-wide collaboration.

## The Problem

Standardized procedures can create real headaches for teams and companies. Often times, these SOP documents get created in a shared drive, and the company is expected to follow them without a collaborative process. Steps might get skipped or done multiple times by different employees, and cost companies time and resources. This app aims to create a real-time shared "source of truth" for teams and allows for efficient and stress-free workflow.

## Features

- **Template Builder** Allows users to create templates for documents that can be used by the team.
- **Live Runs** Users will have the ability to execute a "run" of a template that multiple users execute in real time.
- **Live Sharing** Teams will see the procedural progress of the live template in real-time, allowing for a clear vision of current progress without discrepancy.
- **Team Info** Real time access to other team members' progress or updates.
- **Detailed History** Accessible updated and execution history.

## Technologies
- **UI** React
- **Real-time implementation** Node.js
- **Backend** PostgreSQL with REST API
- **Authentication** Secure user accounts, roles, and companies.

## Intended Users

Businesses that rely on a wide array of standard operating procedures for different aspects of their work, and struggle with keeping an accurate picture of progress and workflow.
