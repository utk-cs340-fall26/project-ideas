# Prism - A Secure Local-First Note-taking Platform

---

## Project Summary
For this project, I propose a locally stored and privacy-focused note management application designed for users who want to build a personal digital knowledge base without being dependent on a cloud service. Prism would combine the flexibility of Markdown-based note-taking with powerful tools for searching, visualizing, and organizing information. Unlike traditional cloud-based applications, Prism would prioritize local storage and user ownership of their data.

---

## Problem It Solves
Many popular note-taking platforms require users to store their information on company-controlled servers or create and online account. This can create concerns about privacy of personal information, data ownership, and fear of losing access to their work. At the same time, basic note-taking applications do not provide enough functionality for users who want to build an interconnected knowledge base. Users need a way to store information securely while also being able to discover relationships between their notes and ideas.

---

## Major Features
- Local-First Storage: Notes are stored directly on the user's device rather than requiring cloud storage.
- Markdown Editer: Users can create and format notes using Markdown while maintaining portable and readable files.
- Interactive Knowledge Chart: A visualization that display relationships between notes and allows users to explore their knowledge base.
- Import/Export: Users can easily import existing Markdown files and export their notes without being locked into the application

---

## Technologies
For this project, we could use TypeScript/Javascript for the user interface, built on top of the Electron framework. HTML and CSS can be used for rendering and styling the user interface, and Markdown will be used as the underlying markup language for writing and formatting notes.

---

## Intended Users
Prism would primarily target students, writers, and developers, or anyone who regularly collect and organize large amounts of information. These users would benefit from having a powerful knowledge-management system without giving up control of their data.
