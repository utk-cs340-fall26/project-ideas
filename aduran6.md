# Project Proposal: All-Purpose Inventory

## Project Summary

I propose an ALL-Purpose Inventory that will track anything. This could include household items, furniture, tech, groceries, and possibly finances. This Inventory will allow the user to organize their assets as they see fit. The user could create different categories, where they then include the assets and any information they need kept. They could add a small sentence detailing what the item is, they could tag the item's price, or they could set the date they purchased the item. The user could add any information they may forget. 

This solves not knowing what you had or when you got an item. For example, if you just got a TV, maybe you want to know how much you paid for it and when you got it. Another thing is if you're a card collector. If you play Magic or Pokémon, you could simply add the card, the image, its current price, and how many you have. Then, if you wanted, you could organize them by the date added or by their worth. 

This project could also be used on things that aren't physical, like if you read books, manga, or watch TV. If the user wanted, they could add a TV show or book, what episode or page they left off on, when they first started and ended the series, and even a description reminding them what they last remembered. Overall, this project lets the user have freedom to keep track of any items or things they deem worth remembering.


## Major Features

- Accounts: allows the user to access their inventory on any device by logging in.
- Custom categories: User has freedom to create categories that hold specific items.
- Custom information: User can add details such as descriptions, prices, dates, and quantity.
- Search & filtering: Users can search for specific items, rather than scrolling.
- Sorting: Allows sorting by date, price, and alphabetically.
- Image displays: Users can upload images of items for easy identification.
- Edits & deletion: allows the user to edit and delete items and categories.
- Timestamps: track when the user creates categories/item.


## Technologies

Programming Language: C++
Frontend: HTML, CSS, and JavaScript
Backend: C++ using the Crow web framework
Database: SQLite
Authentication: Password hashing and session-based authentication

Tools: Git and GitHub

## Intended Users

The intended users for this project is any and everyone that wants to record and organize information that they might forget.
