# Project Idea

Plainboard is a group project manager built for software engineers. It includes features such as user accounts that can join organizations and work together on coding projects. Each individual developer will have their own task list, with milestones, current goals, and progress trackers. Project managers will be able to oversee all developers workflows and progress over time. There will also be group tasks and overall progress milestones for each project as a whole.

# Problems Solved

Plainboard is intended to help track task progress and gameify the development process in groups. Each developer has their own goals they can work on and goals everyone works on as a team. There may be trackers to show how many tasks each developer completes and each developer's overall progress.

# Project Development Tools

The primary languages used will likely be C and its derivatives such as C++. They are the most familiar languages to me and are flexible to work with. APIs are likely to be determined as the project takes a more concrete shape, however it will likely include APIs such as the Slack API to include messaging and notifications relevant to work.

# Intended Users

The intended userbase is software developers and engineers. It is intended to be a flexible program that can adapt to different work groups, situations, and project structures. It is an alternative to other project organizers such as Trello.
