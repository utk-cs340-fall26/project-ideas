# Project Proposal

---

## Idea

The idea for this project is a smart all-in-one bookmarking system. It would allow you to bookmark all sorts of things and have them accessible in one place.

## Objective

Instead of having separate lists of books you want to read, movies you want to watch, recipes you like cooking, and pages with all kinds of useful knowledge, it would be available in one application. The idea is to have a lightweight UI, with flexible data export options. It should ideally run on any desktop OS.

## Features

- Add individual notes to different items
- Automatic detection of item type
- Create lists of any item type
- CSV export features
- General sorting and list management features
- Support for a wide variety of item types, allow creation of new item types  

## Basic Requirements

- C++
- HTTPS requesting
- UI Library
- YouTube API for video identification

## Audience

Users who want to have everything in one place, with convenient features, will be able to add all sorts of items to this application. It will then allow you to create, manage, sort, search, and export these lists for flexibility.
