# Project Pulse

Project Pulse is a platform for managing group projects online designed for college students doing group work. We want to make group projects less chaotic by giving students a single spot to organize tasks, assign work, track deadlines, and check progress. Instead of relying on a mix of group chats, spreadsheets, calendars, and random documents, students could manage the entire project from one simple dashboard.

College group projects often get disorganized, which is the main problem we're trying to solve. Students may be unclear about who is responsible for what, deadlines can be missed, and workloads can become uneven. Project Pulse would make it clear who's responsible and help teams spot workload problems before they're a big problem.

## Major Features

- User accounts and project/team creation
- Task creation, assignment, priorities, and deadlines
- Kanban-style project board
- Task comments and activity history
- Project calendar and upcoming-deadline view
- Workload and project-progress dashboard
- Smart task-assignment recommendations based on workload, deadlines, and skills
- Optional notifications and integrations with tools such as GitHub and Google Calendar

## Technologies

We plan to build the application using TypeScript, React, and Next.js for the frontend and application layer, and use PostgreSQL/Supabase for data and authentication. We would use libraries such as dnd-kit for the Kanban board, Zod for validation, React Hook Form for forms, and Recharts for project analytics. Supabase Realtime could provide live updates, while the GitHub API and Google Calendar API could be added as stretch features.

## Intended Users and Market

Our primary users would be college students, especially students taking courses with team-based assignments. The product could be marketed through universities, student organizations, computer science departments, and campus learning platforms. We could also offer it directly to students with a free version.

## Probability of Success

This project fits well with our team's development skills because it involves full-stack development, databases, UI design, APIs, authentication, and an interesting recommendation algorithm. Overall, we think the probability of success is high because the problem is common, the MVP is achievable in one semester, and the project has plenty of room for additional features if development goes smoothly.
