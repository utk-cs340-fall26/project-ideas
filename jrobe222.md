# Campus Bug Reporter Project Proposal

## Overview

The campus bug reporter would be an app in which any person on campus, students, faculty, etc, can report an issue or anomaly on campus grounds. The user can take a quick photo, input the location, and give a brief description of the issue in order to get it fixed.

## Problem

Often times on campus, there seems to be some issue. The magnitude of the issue may vary from mild inconvenience to a critical obstalce, but in either case, a fix is needed. This app aims to solve that by creating a simple to use reporting tool in which the user enters some information, and then a ticket is made for campus staff. As of now, reporting these issues isn't clear or easy to find, and may not be tracked properly for resolution. In otherwords, a lack of visibilty. This app would serve as the single place to report and track these issues.

## Major Features

- User Reporting that supports an image, a geolocation, a bried description, and a category. 
- Issue tracking for the user that states whether the report is submitted, under review, assigned, in progress, or resolved.
- Search/Filtering via location, category, status, and date for user and administatrators so that users can see if something has already been reported, and admins can see what clustering of reports exist.
- Duplicate Reporting Ticket Merging
- Admin Dashboard
- Notifications

## Tech Stack

- Frontend: React
- Backend: Node.js + Express
- Database: PostgreSQL
- Maps: OpenStreetMap + Leaflet
- Dev Tools: GitHub, VSCode

## Intended Users

The intended users of this would be the students/falculty with an isse, and the adminitstators/ campus staff. The former would need this to solve the issues that might plague them on a daily basis. The latter would need this as a easy to use ticketing system that is easy to track and report status updates.
