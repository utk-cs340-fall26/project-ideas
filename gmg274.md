## Project Idea

For my project, I’d like to create an app that allows users to discover interesting events and activities happening around them. The main idea is to bring event information from multiple sources into one easy to use platform while allowing the results to be personalized for each user.

---

## Problem It Solves

People often miss events happening in their town simply because they don’t know they’re happening in the first place. Information about big and small events can be hard to find because they’re all spread across different websites, social media pages, and even just posters. Unless you’re looking up something very specific, you’re likely to miss an event you might have been interested in attending. 

For example, I often enjoy looking for events that include activities or even free food, but even when I regularly check online, I still miss many events. This project would help make the process easier by bringing events into one place and helping users discover and attend events in their community they’ll likely enjoy. 

---

## Major Features

- User accounts and profiles with customizable interests and preferences
- Event search by filtering by date, category, distance, and price
- Personalized recommendations for each user based on imputed preferences, saved events, and previous events attended
- Detailed event pages with descriptions, dates, locations, prices, and links to vendors or main event page
- System that allows users to submit events, allowing local organizations or community members to add events
- A system that can retrieve data from trusted sites about potential events

---

## Technologies

For this project, I plan to use HTML, CSS, and JavaScript. While I’m not currently sure of which database would be best suited for this project’s needs, after doing some research I’m considering something like PostgreSQL. It’d be ideal to be able to extract information from something like the TicketMaster’s Discovery API as an initial source of event information. Git and GitHub will be used for version control and collaboration.

---

## Intended Users

The intended users are people who want to find things to do in their local area but are having trouble finding information. This could include a variety of people from college kids, young adults, families, people who are new to the area, or anyone just interested to see what’s happening in their town. People who want this are those who likely enjoy attending events but might have trouble finding out what’s happening around them. It could even help those find others with similar interests or find things to do within a set budget.
