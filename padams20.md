# Project: Buzzati

---

## Summary and Features:

Buzzati is meant to be a lightweight mobile app people can use to find books similar to each other. Ideally, it would be deployed on a phone or tablet, and have UI simple enough to operate on the fly-say, while in a library combing through books. There's a few apps that can provide book recommendations already, but the aim of PocketLib would be to make this process much more simple; for example, Goodreads, one of the most popular book-recommendation sites, has clunky UI and requires a web browser to work, which, while fine on a laptop, is often difficult to navigate on a phone. Goodreads' phone app, on the other hand, is clunky and requires you to sign in to track your reading. Optimally, this app would only require two button presses before it gives a recommendation. Also, the app would have a very basic search function that would take a book title and compare it against existing books to determine its overall character; this would help when a user is simply scanning through library shelves looking for something they may like. The app would also need a comprehensive list of books the user likes, so that it may recommend more books the user may like before they even go to the library. However, this feature would be extremely limited, as the aim is not to compete directly with other book-recommendation sites, but to provide those same services in a smaller, quicker format.

The name "Buzzati" comes from Dino Buzzati, the author of "The Tartar Steppe." I wouldn't know about Buzzati were it not for his similarity to another author I enjoy, so his name is, personally, a fitting choice for a book-similarity site. Plus all the other names I could think of were taken.

## Tools

This project could use c++ for the backend, and python for the recommendations. The easiest way to get decent recommendations is to download a dataset (or multiple) on Kaggle and run an ML algorithm to determine book similarity. This is be similar to a project we have to do for an intro to Machine Learning class, so it should be doable with the tools we have access to.

---

## Users

The intended users are people (like me, honestly) who regularly check books out from the library and often need to find a good book quickly. In between classes, I don't have a lot of time to do adequate research on a book, but this app would solve that problem by streamlining the book discovery process.
