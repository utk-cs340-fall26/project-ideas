# Project Proposal - Typing game 

---

## Project Summery

When looking at the list educational games out there, a lot center around teaching basic math skills, different science or history facts, or how to type. The game that I envision to make is based on that last point. It will be aimed around teaching speed and accuracy above all by having competitive leaderboards that can be limited to a small group of people to everyone who has ever played this game. 

---

## What problem this would solve

One common downfall that I have noticed with every typing game I have ever interacted with is that they are all web based and they all are full of ads. With this game you can download it directly to your computer and use it as much as you like. In addition it will teach you basic typing skills like using the home row, increasing your words per minute, and having less errors in your typing.

---

## Major features

- A base typing mode where users are given a story to type and the game keeps track of the words per minute, how many mistakes are made, and time to complete.
- Reaction based mode where a random letter, word, or phase pops up and the user types it.
- Account based system there the game tracks the user's progress and compares it with other users via a leaderboard.
- Ability for users to add there own custom sentences/stories for them to type.

---

## List of technologies that may be potenially used

- **Languages**: C++, Python
- **C++ Libaries**: Unreal, Raylib, SFML (Simple and Fast Multimedia)
- **Python Libaries**: Pygame, Tkinter, PyInstaller

## Customer base

The primary customer base would be primary schools as that is when schools aim to introduce kids to computers and by proxy, typing. It can also be used by people who want to improve their words per minute for their jobs. (Sectaries, data entity specialists, etc.)
