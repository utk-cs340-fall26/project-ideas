# **Final Proposal**

# **Project Summary**

For the final proposal idea, it would be a cooking and nutrition application. The main selling features of the application would be to allow users to upload and share recipes amongst each other, and allows users of learn and manage basic nutritional information. Users would be able to search up recipes for their dietary needs and preferences while understanding the nutritional benefits and concerns of the foods and dishes they consume everyday.

# **What Does this Solve?**

In most applications that offer similar services to this proposed project, they tend to solely focus on cooking and sharing recipes, or solely focus on tracking, managing, and understanding nutrition and nutritional health. The problem that many consumers of these applications face are either 1 of 2 scenarios: those that are concerned about their dietary health are able to track, manage, and understand their nutritional health, but fail to find recipes that accommodate to said needs. The other scenario is that those use apps to find and share recipes typically are not aware of the benefits, disadvantages,and general health informmation that comees with the consumption of the foods that they eat, or lacks trusted verified sources about nutritional health with the amount of misinformation seen online. This project attempts to bridge the gap between these two areas by allowing users to upload, find and try different recipes created by others while simultaneously provide trusted verified sources that will offer dietary and nutritional information in a user-friendly manner to better help the user's understanding about their nutritional health.

# **Major Features**

Some of the major features that would be included with this project are...

* Provides uploading of recipes via snapshotting photos.

* Provides a search feature that allows users to search for particular recipes.

* Provides a filter feature to sift through recipes and customize their experience towards their dietary restrictions and preferences.

* Provides a feature to allow users to save and archive "Favorited" recipes.

* Provides a nutrition tab, which offers nutritional information of the recipe.

* Provides translations option for recipes and nutritional information in several languages.


# **Project Requirements**

Some of the tools and infrastructures that this project would require are. . .

* Frontend: some development tools to create the user interface such as React or Flutter.

* Backend: some development tools to set up and manage databases and logisitics would be Node.js/Express or Python/FastAPI.

* Database: some development tools to organize and manage recipes/nutrition information would be Supabase or Postgres.

* Nutrition Data: using APIs to help such as Spoonacular, Edamam of the USDA Food database.

* Translation: some development tools to help translate recipes and other terminology with Google Cloud Translation API or a translation cache table.

* Hosting: some development tools to help with hosting the service such as Supabase, or for more specifically for front-end Vercel/Netli, and for back-end Railway/Render.

# **Intended Consumerbase**

The intended userbased for this project would those with a passion for culinary, culture exploration, and nutrition-oriented individuals that want to have a better understand with their nutritional health. This project would appeal to these users as it provides verified information about foods and dishes and also gives opportunities to discover, create and share recipes for both enjoyment and nutritional value.
