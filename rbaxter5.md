My proposal is to create a Goal-Driven Behavioral Finance Tracker.

The Goal-Driven Behavioral Finance Tracker will be an application that logs users' income and expenses, helping them create savings by setting personal spending goals. When given a goal (such as spending < $500 in a month) the app tracks a user's expenses and progress towards reaching their goal. The app then uses this expense data to determine a user's spending habits and uses this data to help the user fix bad habits through clear data-backed messages. It also uses this data to predict future expenses and can calculate a user's total savings given different behaviors. (eg. Right now you make $500 a month, but if you spent less on clothes you could be making a net $650 a month) It will be marketed as private and secure and will only host data locally, allowing users to feel safe trusting it with their financial information.

This will allow users see the tangible effects of their poor spending habits and give suggestions to mitigate these habits. This helps solve the problem of reckless spending.

Features:
* Goal-Focused Bugeting System
* Net Income Reporting
* Basic ML Predictive Analysis
* Future Income Prediction Reports
* Self-Help Resources

Technologies:
Frontend (Web) - React.js
Frontend (Mobile) - Flutter
Backend - Python
Analytics - pytorch & pandas

Possible users are those who struggle with shopping addictions or otherwise unwise spending habits looking to save money. The code for the app will also be open source and all data will be hosted locally so users can be sure they are not being taken advantage of. A budgeting app that personalizes itself to the user while also visibly not taking advantage of vulnerable shoppers by charging for a subscription or otherwise selling their data would be valued among consumers. People are more likely to trust the app with sensitive details about their spending habits if they know this information will not be used elesewhere.
