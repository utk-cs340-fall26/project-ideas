# Project Proposal

Coding can get boring. It’s absolutely bound to happen. But I want to make it something fun, 
refreshing, and gamified. I want to build an extension that works in any IDE and tracks coding 
metrics you haven’t even begun to think about. Have you ever wondered which language you use the most? 
How efficient is your code compared to millions of other software engineers? This extension will track both 
of these things and more. The metrics that will be included are a breakdown of the languages you use most,
how efficient your code is, how fast you code, the length of the coding session, and your downtime vs. the 
time you actually spend coding. The tools and languages required as of now are TypeScript, VS Code Extension
API, Node.js, Python, WebSockets, REST API, PostgreSQL, React, Chart.js, Tailwind CSS, React Native, and Electron. 
The intended users for the project are the people who I see 5 out of 7 days a week: my classmates. I 
know how it feels to have a billion coding assignments due on Sunday at 11:59 P.M., and I want to do what 
I can to relieve that stress by adding something that makes coding a little less like coding and more like an 
activity you can really enjoy. I want to help that student who gets in a coding slump and can’t finish the
project they’ve been working on.  I want to help that student who tries to do LeetCode to study for an exam
but can’t seem to find the motivation. I want to help as many Computer Science students as possible.
