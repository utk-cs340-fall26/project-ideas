# Project-Idea:

- Name: Alexandre
- Project Idea: Note sharing app with the capability to find studying partners

---

## Description

The basic idea is that this is an app where people can post their own notes to it and search for other people's notes related to the same topic. The user should be able to filter the notes in the app by course and by topic.

---

## Problems it solves

When students are taking notes during class, there will be always something that will be left out, or something that the student thought was not important at the time, but at the end it was and they do not have any notes about it. A lot of students also have a hard time finding people to study with, so the functionality of finding studying partners helps with that too.

---

## Major features

- The user will have a home page where they can list the courses that they are taking, or the courses that they want to find notes for. There they can navigate through the selected courses and find the notes related to those specific classes.
- Each user should be able to upload their notes to the app. And when they upload it, they are required to put a tag on what the notes are about and for which course. The notes will only be separated by courses, independent of instructor or class section, this is because the pool of notes will be greater for all students.
- The user also needs to find the topic they are looking for, so they can search the topic, and the algorithm will select notes with tags that sound like the user's search.
- There will be a social page where people can talk to each other and find people to study together.

---

## Technologies

- Backend language: Python
- Frontend (web): React
- Mobile: React Native
- Database: PostgreSQL
- Topic-matching: rapidfuzz (Python library)
- File storage: Firebase Storage
- Auth: OAuth login through school email (Google)
- API: Canvas API

---
## Intended Users

This app is targeting college students who want to have more access to class notes and find studying partners. This helps students because it offers them more material to study and helps people to find others to help them study or for them to help someone else.
